# CPU Scheduling Algorithm Simulator

A static web app that simulates common CPU scheduling algorithms and visualizes results for a set of processes.

Presentation: https://drive.google.com/file/d/1LversQ96u6QomnmTxXq7XkAyIl0Y7Q0K/view?usp=sharing


Live site: https://sudo-paoo.github.io/cpu-process-scheduling-algorithms/

## Features
- Configure processes with arrival, burst, and priority values
- Simulate FCFS, SJF, SRT, Round Robin, Priority, and Priority + RR
- Display a Gantt-style timeline and computed metrics

## Project Structure
- `index.html` - main UI and layout
- `assets/css/styles.css` - styling and layout
- `assets/js/main.js` - UI logic and orchestration
- `assets/js/algorithms/*.js` - scheduling algorithm implementations

## How to Run Locally
- Open index.html directly in a browser, or
- Use a lightweight server, for example:
  - VS Code Live Server extension
